# NIBS-SES - The Non-Invasive Brain Stimulation Side Effect Scale

The NIBS-SES is an open-access questionnaire that measures the side effects and tolerability of non-invasive brain stimulation, including transcranial magnetic stimulation (TMS), transcranial electrical stimulation (tES), and transcranial ultrasound stimulation (tUS). It is designed for repeated use across sessions and records both the acute effects during a session and the delayed effects between sessions.

The primary archive of the NIBS-SES is the Open Science Framework (https://doi.org/10.17605/OSF.IO/XZ3NB). This repository holds the same files.

## Files

The current version is 1.1. Each language folder contains the following files. Import instructions for each platform are given in Section 5 of the user manual.

- **Questionnaire PDF** for paper-and-pencil use
- **REDCap**, instrument ZIP
- **Qualtrics**, .qsf file
- **SoSci Survey**, .xml file (one file with all 16 languages, identical in every folder)
- **User manual**

The digital versions store the 0 to 4 rating scales as 1 to 5. Subtract 1 from each stored rating to obtain the 0 to 4 score of the questionnaire. Answers to yes/no questions are stored as 1 (yes) and 2 (no). The user manual describes administration, scoring and the import of the digital versions.

The table [items/NIBS-SES_items_v1.1.csv](items/NIBS-SES_items_v1.1.csv) lists the wording of all items in the 16 languages.
