# Non-Invasive Brain Stimulation Side Effect Scale (NIBS-SES)

**Escala per a la valoració dels efectes adversos de la estimulación cerebral no invasiva**

La versió catalana de la NIBS-SES és un qüestionari sobre els efectes adversos de l'estimulació magnètica transcranial (TMS), l'estimulació elèctrica transcranial (tES) i l'estimulació transcranial amb ultrasons (tUS), que es pot utilitzar de manera repetida després de cada sessió de tractament.

Aquesta carpeta conté el qüestionari en PDF, el manual d'usuari en anglès i fitxers per importar directament a REDCap, Qualtrics i SoSci Survey. El qüestionari es pot utilitzar gratuïtament amb la llicència CC BY 4.0.
