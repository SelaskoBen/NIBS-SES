# Non-Invasive Brain Stimulation Side Effect Scale (NIBS-SES)

The English (original) version of the NIBS-SES is a questionnaire on adverse effects of transcranial magnetic stimulation (TMS), transcranial electrical stimulation (tES) and transcranial ultrasound stimulation (tUS) for repeated use after each treatment session.

This folder contains the questionnaire as PDF, the user manual and files for direct import into REDCap, Qualtrics and SoSci Survey. The questionnaire is free to use under the CC BY 4.0 license.
