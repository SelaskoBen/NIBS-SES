# Non-Invasive Brain Stimulation Side Effect Scale (NIBS-SES)

<p dir="rtl"><b>مقياس تقييم الآثار الجانبية لتحفيز الدماغ غير جراحي</b></p>

<p dir="rtl">النسخة العربية من NIBS-SES استبيان لتقييم الآثار الجانبية للتحفيز المغناطيسي عبر الجمجمة (TMS) والتحفيز الكهربائي عبر الجمجمة (tES) والتحفيز بالموجات فوق الصوتية عبر الجمجمة (tUS)، ويمكن استخدامه بشكل متكرر بعد كل جلسة علاج.</p>

<p dir="rtl">يحتوي هذا المجلد على الاستبيان بصيغة PDF ودليل المستخدم باللغة الإنجليزية وملفات للاستيراد المباشر إلى REDCap وQualtrics وSoSci Survey. يمكن استخدام الاستبيان مجانًا بموجب ترخيص CC BY 4.0.</p>

The Non-Invasive Brain Stimulation Side Effect Scale (NIBS-SES): development of a brief, multilingual questionnaire for monitoring adverse effects in transcranial magnetic, electrical and ultrasound stimulation.
